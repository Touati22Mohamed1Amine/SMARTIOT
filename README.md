# 🏠 Smart House IoT Project  
### Cisco Packet Tracer Simulation

---

## 🌟 Introduction
Welcome to the **Smart House IoT Project**, a complete smart home simulation built using **Cisco Packet Tracer**.  
This project demonstrates how **IoT technologies** can automate, monitor, and secure a modern house using sensors, smart devices, and network communication.

The system allows users to control home components locally and remotely using a **laptop** or **smartphone**.

---

## 🚀 Key Features
✨ This Smart House provides several intelligent services:

### 🔐 RFID Access Control
- Open **doors** and **windows** using an RFID card.
- Secure and simple authentication system.

### 🚨 Motion Detection & Security
- Motion sensors detect any movement inside or outside the house.
- LEDs light up to visually confirm motion detection.
- A **siren** is automatically triggered in case of movement.
- Automatic **email alerts** are sent for security notifications.

### ☕ Smart Appliances
- Automated **coffee machine** control for user convenience.

### 🏡 Smart Home Areas
- 🚗 **Smart Garage**
- 🌿 **Smart Garden**
- 🏠 **Smart House Detection System**

---

## 📡 Motion Detectors Roles
The project uses **three motion detectors**, each assigned to a specific task:

| 🔍 Motion Detector | 🎯 Function |
|-------------------|------------|
| Motion Detector 1 | Opens the garage door 🚗 |
| Motion Detector 2 | Activates garden cleaning / watering 🌿 |
| Motion Detector 3 | Detects movement inside the house 🏠 |

---

## 🧠 Automation & Scripts
To ensure full functionality, the following automation scripts must be executed:

- 📧 **SendingEmail** → Sends an email when motion is detected  
- 🔁 **motionTrip** → Manages motion detection and LED activation  

⚠️ **Both scripts are required** for the system to work correctly.
